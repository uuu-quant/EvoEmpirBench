Benchmark Tasks

Both tasks require sequential decision-making under feedback rather than static one-shot answering.

Maze Navigation

Agents see only local observations, collect coins, avoid or defeat monsters, use tools, and reach the goal across 7x7, 9x9, and 11x11 levels.

Match-2 Elimination

Agents clear connected color blocks on an 8x8 board while balancing color targets, limited steps, and one-shot props.

Online Experience

Agent-ExpVer abstracts subjective traces, validates whether they improve behavior, and promotes robust rules into reusable truth knowledge.

Agent-ExpVer Loop

The method is a harnessed online learning loop: every episode is run, logged, abstracted, replay-validated, and converted into reusable in-context truth only when it improves behavior.

Scenario Ablations

Control settings show why the benchmark is hard: partial observability, tool constraints, and truth management all shape performance.

Maze visibility

Full vision removes exploration pressure

to
93.33Full-Vis SR

When the map is globally visible, planning becomes much easier, confirming that local observation is a core difficulty source.

Match-2 props

Tools change the objective trade-off

to
412.67NoProps AS

Removing props can raise raw score, but it also removes the decision pressure of when to spend tools for target completion.

Validated memory beats loose reflection

TruthWeaver keeps only useful, reusable knowledge, reducing noisy memories before they enter later prompts.
