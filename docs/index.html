Benchmark Tasks

Both tasks require sequential decision-making under feedback rather than static one-shot answering.

Maze Navigation

Agents see only local observations, collect coins, avoid or defeat monsters, use tools, and reach the goal across 7x7, 9x9, and 11x11 levels.

Match-2 Elimination

Agents clear connected color blocks on an 8x8 board while balancing color targets, limited steps, and one-shot props.

Online Experience

Agent-ExpVer abstracts subjective traces, validates whether they improve behavior, and promotes robust rules into reusable truth knowledge.

Agent-ExpVer Loop

The mechanism turns episode traces into verified in-context knowledge without fine-tuning the base model.

  1. InteractGeoLink observes local state, selects actions, and collects environment feedback.
  2. AbstractInsightForce summarizes successful and failed trajectories into subjective experience.
  3. ValidateThe agent replays with candidate memories and checks whether metrics improve.
  4. MaintainTruthWeaver inserts, merges, removes, and reuses verified truth knowledge in later episodes.
